┌───────────────────────────────────────────────────────────────────────────┐
│ 🚨 TROUBLESHOOTING                                                        │
└───────────────────────────────────────────────────────────────────────────┘
Services not starting:
  → docker-compose down && docker-compose up --build

Port already in use:
  → sudo lsof -i :8000
  → kill <PID>

Migrations fail:
  → Check .env file exists
  → docker-compose run --rm web pip install Pillow python-dotenv
  → docker-compose restart web

CORS errors:
  → Verify CORS_ALLOWED_ORIGINS in api/config/common.py
  → docker-compose restart web

Images not uploading:
  → Check Pillow installed: pip list | grep Pillow
  → Verify MEDIA_URL in settings
